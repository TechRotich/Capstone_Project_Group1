## Project Overview
Public Service Vehicles (PSVs)—such as buses, matatus, and other forms of public transport—require efficient management for effective operation. 

The notebooks in this repository explore data processing, analysis, and model building to improve various aspects of PSV oversight. These include compliance , route optimization through fleet categorization and vehicle classification.


## Notebooks

### Objective1_Capstone.ipynb
**Focus:** 
Develop an AI system to classify PSVs and assist law enforcement in detecting non-compliant vehicles to enhance road safety.

### Objective2_Capstone.ipynb
**Focus:**
To build a system that can identify and track Public Service Vehicles in real-time using YOLOv8, a deep-learning model. 
  
### Objective3_Capstone.ipynb
**Focus:**
 Automate fleet tracking and classification for transport operators to monitor vehicle conditions, optimize maintenance, and ensure regulatory compliance.
